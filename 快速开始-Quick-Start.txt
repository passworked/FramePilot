【中文】

重要：请先解压整个 ZIP。不要只复制 EXE，也不要直接在压缩包内运行。

运行条件
1. Windows 10/11 64 位。
2. SteamVR 已安装并正常运行。
3. 头显已连接，并运行一个 SteamVR VR 游戏。
4. 不需要安装 Python，也通常不需要管理员权限。

启动方法
1. 将 ZIP 解压到桌面、文档或其他可写目录。
2. 启动头显软件、SteamVR 和 VR 游戏。
3. 双击 start_panel.bat，或直接运行 FramePilotVR.exe。
4. 在顶部选择“中文”。
5. 第一次使用保持“只读监控”，不要勾选写入解锁。
6. 选择原生刷新率，或刷新率的 1/2、1/3、1/4。72 Hz 会自动对应 72/36/24/18 FPS 预算。

推荐顺序
1. 观察 GPU/CPU P95、帧预算和建议值。
2. 在代表性场景中运行 45–90 秒“只读校准”。
3. 需要测试动态修改时，打开“高级模式”，先解锁写入并只用“单步自动调整”。
4. 确认游戏能实时响应后，再考虑精确阶梯或连续自适应。

安全与文件
- 默认只读；面板退出时会强制恢复启动值。
- 刷新率分频只改变动态分辨率帧预算，不是游戏限帧器；实际帧率由游戏和 SteamVR 重投影决定。
- 普通模式只显示预设、只读/连续、刷新率分频、写入解锁和只读校准；阈值、步长、上下限、单步、精确校准、策略迁移及手动设置在高级模式。
- 日志在程序目录的 logs 文件夹。
- 本机校准在 %LOCALAPPDATA%\SteamVRAdaptiveResolution\strategy-store.json。
- 发送给别人时发送完整 ZIP，不要只发 EXE，也不要附带个人日志。
- Windows SmartScreen 可能提示未知发布者，因为程序未做代码签名。只在来源可信且校验值一致时选择“更多信息 → 仍要运行”，不要关闭杀毒软件。


[ENGLISH]

Important: extract the entire ZIP first. Do not copy only the EXE and do not run it from inside the archive.

Requirements
1. 64-bit Windows 10 or Windows 11.
2. SteamVR installed and working.
3. A connected headset and a running SteamVR VR game.
4. Python is not required, and administrator rights are normally unnecessary.

How to start
1. Extract the ZIP to Desktop, Documents, or another writable folder.
2. Start the headset software, SteamVR, and the VR game.
3. Double-click start_panel.bat, or run FramePilotVR.exe directly.
4. Select “English” at the top of the panel.
5. Keep “Read-only monitor” selected and writes locked on first use.
6. Select the native refresh rate or 1/2, 1/3, or 1/4 of it. At 72 Hz these become 72/36/24/18 FPS budgets automatically.

Recommended workflow
1. Observe GPU/CPU P95, frame budget, and the recommendation.
2. Run “Read-only calibration” for 45–90 seconds in a representative scene.
3. To test live changes, enable “Advanced mode,” unlock writes, and use “One-step adjustment” first.
4. Use precise steps or continuous adaptive mode only after the game responds correctly at runtime.

Safety and files
- The default mode is read-only. The panel always restores the startup value when it exits.
- Refresh-rate division changes the dynamic-resolution budget; it is not a game FPS limiter. Actual frame rate depends on the game and SteamVR reprojection.
- Basic mode shows presets, read-only/continuous mode, cadence, write unlock, and read-only calibration. Thresholds, steps, range, one-step mode, precise calibration, policy migration, and manual controls are in Advanced mode.
- Logs are stored in the logs folder beside the program.
- Local calibration is stored at %LOCALAPPDATA%\SteamVRAdaptiveResolution\strategy-store.json.
- Share the complete ZIP, not only the EXE, and do not include personal logs.
- Windows SmartScreen may report an unknown publisher because the app is unsigned. Use “More info → Run anyway” only when the source is trusted and the checksum matches. Do not disable antivirus protection.
