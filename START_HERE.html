中文

1. 运行条件

  • Windows 10/11 64 位。
  • 已安装并能正常运行 SteamVR。
  • 头显已通过原厂软件或串流软件连接。
  • 运行一个 SteamVR 游戏；无需安装 Python。
  • NVIDIA GPU 可显示系统 GPU 占用率；AMD/Intel 可能显示 n/a，但 SteamVR 帧时间仍可读取。

2. 第一次启动

  1. 把 ZIP 解压到桌面、文档或其他可写目录。
  2. 依次启动头显软件、SteamVR 和 VR 游戏。
  3. 双击 start_panel.bat；也可以直接运行 FramePilotVR.exe。
  4. Guide 第一页先选择“简体中文”；也支持 English、日本語、한국어、Français、Deutsch 和 Español，选择后界面会立即切换。
  5. Guide 最后一步可手动勾选“允许 FramePilot VR 调控 SteamVR 分辨率”；默认不勾选，选择会保存到本机，直到主动取消。
  6. 若希望以后由 FramePilot VR 启动 SteamVR，勾选“启动 FramePilot VR 时自动启动 SteamVR”；保存后从下次启动生效。
  7. 选择原生刷新率，或刷新率的 1/2、1/3、1/4；72 Hz 会自动对应 72/36/24/18 FPS 预算。
  8. Guide 最后一步还会默认勾选自动上传匿名聚合记录；不希望上传时取消勾选，之后也可在主面板随时关闭。

3. 推荐使用顺序

  1. 先只读：观察 GPU P95、CPU P95、帧预算和建议值。
  2. 在代表性游戏场景中运行 45–90 秒“只读校准”。
  3. 若要验证动态修改，打开“高级模式”，勾选“允许 FramePilot VR 调控 SteamVR 分辨率”，再使用“单步自动调整”。
  4. 确认游戏能在运行中响应后，才考虑“精确阶梯”或“连续自适应”。

4. 安全提示

  • 写入许可默认关闭；手动勾选或取消后都会缓存。只读状态不会自动修改 SteamVR。
  • 精确阶梯会测试当前值、-10% 和 +10%，结束时恢复原值。
  • 面板退出时始终恢复启动值；该安全项不再暴露为可关闭选项。
  • 部分游戏只有重启后才读取新的分辨率。
  • 刷新率分频只是动态分辨率预算，不是游戏限帧器。实际帧率仍由游戏和 SteamVR 重投影决定。
  • “分辨率调节范围与规则”不会被程序自行修改；自动变化的只有 SteamVR 分辨率。规则、单步、精确校准、策略迁移和手动设置位于高级模式。
English

1. Requirements

  • 64-bit Windows 10 or Windows 11.
  • SteamVR installed and working normally.
  • A headset connected through its vendor software or streaming software.
  • A SteamVR game running; Python is not required.
  • NVIDIA GPUs expose system GPU usage. AMD/Intel may show n/a, while SteamVR frame timing still works.

2. First launch

  1. Extract the ZIP to Desktop, Documents, or another writable folder.
  2. Start the headset software, SteamVR, and then the VR game.
  3. Double-click start_panel.bat, or run FramePilotVR.exe directly.
  4. Choose “English” on the first Guide page. Simplified Chinese, Japanese, Korean, French, German, and Spanish are also available, and the interface updates immediately.
  5. On the final Guide page, manually enable “Allow FramePilot VR to control SteamVR resolution” if wanted. It is off by default and the choice is saved on this PC until changed.
  6. To have FramePilot VR launch SteamVR in the future, enable “Start SteamVR automatically with FramePilot VR.” The saved option takes effect on the next launch.
  7. Select the native refresh rate or 1/2, 1/3, or 1/4 of it. At 72 Hz these become 72/36/24/18 FPS budgets automatically.
  8. The final Guide step also enables automatic upload of anonymous aggregates by default. Clear that checkbox to keep data local; it can also be changed later in the main panel.

3. Recommended workflow

  1. Start read-only: inspect GPU P95, CPU P95, frame budget, and the recommendation.
  2. Run “Read-only calibration” for 45–90 seconds in a representative scene.
  3. To validate live changes, enable “Advanced mode,” select “Allow FramePilot VR to control SteamVR resolution,” and try “One-step adjustment” first.
  4. Use “Precise steps” or “Continuous adaptive” only after the game responds correctly at runtime.

4. Safety notes

  • Write permission is off by default; manual enable/disable choices are cached. Read-only mode does not change SteamVR automatically.
  • Precise calibration tests the current value, -10%, and +10%, then restores the original value.
  • The panel always restores the startup value on exit; this safety behavior can no longer be disabled in the UI.
  • Some games only read a new resolution after restarting.
  • Refresh-rate division changes the dynamic-resolution budget; it is not a game frame limiter. Actual frame rate still depends on the game and SteamVR reprojection.
  • “Resolution adjustment range and rules” are not rewritten automatically; only SteamVR resolution changes. Rules, one-step mode, precise calibration, policy migration, and manual controls are under Advanced mode.

旧版固定 FPS 策略仍可导入，并在高级模式中显示为“旧策略自定义”；新策略推荐保存刷新率分频，因此换头显刷新率后会自动适配。

English

Migration, logs, and troubleshooting

Sharing with another person

Send the complete ZIP. Do not include personal logs generated after running the program. A portable policy may be exported separately; it excludes the hardware fingerprint and local final resolution.

Older fixed-FPS policies remain importable and appear as “Legacy custom” in Advanced mode. New policies should use refresh-rate division so they adapt automatically to another HMD refresh rate.

File locations

  • Runtime logs: logs beside the application.
  • Local calibration: %LOCALAPPDATA%\SteamVRAdaptiveResolution\strategy-store.json.
  • Anonymous collection data: %LOCALAPPDATA%\SteamVRAdaptiveResolution\shared-telemetry. Automatic uploads batch 25 records or wait 15 minutes; rate limits and failures do not delete local records.

Common issues

  • Waiting for SteamVR: verify that vrserver.exe is running.
  • Waiting for scene application: enter a VR game instead of remaining only in SteamVR Home.
  • System GPU shows n/a: SteamVR GPU frame-time control still works.
  • Windows SmartScreen: this is an unsigned locally built app. Use “More info → Run anyway” only when the source is trusted and the checksum matches. Do not disable antivirus protection.
