# 商品説明

FramePilot VRは、Windows / SteamVR向けの動的解像度コントローラーです。

OpenVRのフレームタイミングとCPU・GPU負荷を監視し、現在のシーンに合わせてSteamVRの解像度スケールを段階的に調整。重い場面では画質を下げ、余裕が戻れば慎重に上げることで、目標フレームレートの維持をサポートします。

## 主な機能

### 1. VR内OSD

FPS、GPU/CPUフレーム時間、GPU使用率、フレーム予算、解像度、再投影、VRChatのワールド／人数コンテキストをヘッドセット内に表示できます。

### 2. 自動解像度調整

設定したフレーム予算と現在の負荷を比較し、SteamVRの`resolutionScale`を段階的に調整します。

初期状態は読み取り専用です。解像度の変更は、ユーザーがガイドまたはメインパネルで明示的に許可した場合のみ行われます。この選択はPCに保存され、いつでも解除できます。

### 3. 匿名テレメトリとWorld Bench

実プレイから得た匿名の集計データを共有し、ワールドごとの負荷傾向を確認できます。

送信されるデータには、ワールドID、人数範囲、ハードウェアモデル、レンダリング設定、集計済みパフォーマンス指標が含まれます。

プレイヤーID、VRChatインスタンスID、マシン名、ハードウェア指紋は送信されません。アップロードはいつでも無効にできます。

### 4. 目標は、いつでもフルフレーム

重い場面では画質を下げ、パフォーマンスに余裕が戻れば画質を上げる——フレーム予算を守るための動的解像度制御です。

※ フルフレームを保証するソフトではありません。ゲーム側の負荷、CPUボトルネック、VRストリーミング、ネットワークなどの条件により、目標FPSを維持できない場合があります。

## 対応環境

- Windows x64

## はじめ方

1. FramePilot VRを起動
2. 表示言語と目標フレーム予算を選択
3. まずは読み取り専用モニターで負荷を確認
4. 必要な場合のみ、ガイドまたはメインパネルで解像度変更を許可
